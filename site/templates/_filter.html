{# The catalogue search box. Emitted by the {% block filter %} in base.html, so ONLY the pages that include it get any JavaScript at all — /movies/, /watching/, /shelf/, /quotes/, /games/ and /ideas/. The home page and the blog still ship none. Three deliberate choices: 1. The input is created by the script, not by the markup. A reader with JavaScript off never sees a search field that cannot search. 2. Matching is done against a data-find attribute the template writes, so a film matches on its title, year and genre without anyone having to search the rendered HTML for stray words like "IMDb". 3. Filtering toggles a class instead of removing nodes. Nothing reflows into a different grid, and clearing the box restores the original order exactly — which a remove-and-reinsert approach does not. #}
