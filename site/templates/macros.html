{# Icons, as macros. Every mark on this site is an inlined SVG path rather than an icon font, a sprite sheet or a CDN link. Three reasons, in order of how much they matter: 1. No request. An icon font is a render-blocking download for glyphs that are already in the HTML you just sent. 2. No third party. Pulling GitHub's or X's own assets would leak every visitor's IP to them on a page whose entire pitch is that it does not do that. 3. currentColor. These inherit the colour of whatever they sit inside, so the same mark works on a white pill and on an inverted one with no second copy. The brand marks below are each platform's own published logo path, which is the only way for the feed sections to read as authentic. Everything else is drawn here. #} {% macro github() %}{% endmacro github %} {% macro x() %}{% endmacro x %} {% macro linkedin() %}{% endmacro linkedin %} {% macro mail() %}{% endmacro mail %} {% macro doc() %}{% endmacro doc %} {% macro rss() %}{% endmacro rss %} {% macro back() %}{% endmacro back %} {# --- GitHub island -------------------------------------------------------- #} {% macro star() %}{% endmacro star %} {% macro fork() %}{% endmacro fork %} {# --- X island ------------------------------------------------------------- #} {# Stroked rather than X's own filled glyphs: the action row is decoration here, and a stroked set sits better next to the rest of the page. #} {% macro reply() %}{% endmacro reply %} {% macro repost() %}{% endmacro repost %} {% macro like() %}{% endmacro like %} {% macro views() %}{% endmacro views %} {# --- LinkedIn island ------------------------------------------------------ #} {% macro thumb() %}{% endmacro thumb %} {% macro comment() %}{% endmacro comment %} {% macro send() %}{% endmacro send %} {# --- misc ----------------------------------------------------------------- #} {% macro check(done=false) %}{% if done %}{% else %}{% endif %}{% endmacro check %} {% macro chess() %}{% endmacro chess %} {# --- Steam island --------------------------------------------------------- #} {% macro steam() %}{% endmacro steam %} {% macro clock() %}{% endmacro clock %} {% macro trophy() %}{% endmacro trophy %} {% macro cart() %}{% endmacro cart %} {# --- Duolingo island ------------------------------------------------------ #} {# Not Duolingo's own owl — that is their trademark and is not ours to ship. The map has to be passed in because a Tera macro cannot see globals — which is the right constraint here: it makes these pure functions of a snapshot. `tint` paints the mark in the brand's own published colour; without it the mark inherits currentColor, which is what you want on a coloured tile where the logo is knocked out in white. Referenced from me.toml as "g:name". #} {% macro glyph(name) %} {%- if name == "monitor" -%} {%- elif name == "cup" -%} {%- elif name == "bowl" -%} {%- elif name == "steak" -%} {%- elif name == "burrito" -%} {%- elif name == "chips" -%} {%- endif -%} {% endmacro glyph %} {# One call site for both kinds: "g:cup" draws a glyph, anything else is a Simple Icons slug.
