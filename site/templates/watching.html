{% if titles.posters %}

Where these come from

Posters are from TMDb, which licenses its API so applications can show this artwork. Two conditions come with that and both are met here: the attribution line below, and serving the images from TMDb's own CDN rather than re-hosting them. That makes these posters the only thing on this site your browser fetches from somewhere else — see POSTERS.md.

{{ titles.posters.attribution }}

{{ titles.with_logo }} shows also have a title logo from Wikimedia Commons, used where TMDb has no poster. Everything else — the year, the genres, the IMDb link — comes from Wikidata, which is CC0.

{% else %}

Why there are no posters

Key art is copyrighted and has no free source at any size. Wikipedia's own poster files are tagged non-free — they are fair use on Wikipedia, which does not travel to anyone else's site. So {{ titles.with_logo }} of these carry a real title logo, because a wordmark set in a typeface is often below the threshold of originality and therefore public domain, and the rest are set in this site's own type on a colour picked by hand.

Everything else — the year, the genres, the IMDb link — comes from Wikidata, which is CC0.
